# UIDAI Horizon

An academic concept redesign of uidai.gov.in, ten years forward (2036), built for
IIIT Hyderabad's "AI for Product Managers" coursework. Unofficial student work;
not affiliated with UIDAI. All flows use fictional data - no real Aadhaar number,
OTP or personal information is requested or stored.

## Contents
- Portal 2036: life-event homepage with guided services
- Services 2036: DigiLocker-verified address update, selective zero-knowledge e-Aadhaar credentials, live SRN/PVC tracking
- Aadhaar Seva Kendra discovery and booking
- Ecosystem and help views, Bhashini 22-language voice assistance concept

## Build
```
npm install
npm run build    # outputs dist/
npm run dev      # local dev server
```
